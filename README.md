explaination  For Part 2, I improved my Greenleaf Garden Services website by creating an external CSS stylesheet called style.css and linking it to all my HTML pages. The CSS controls the colours, fonts, spacing, navigation bar, buttons, images and overall layout of the website. I used Flexbox for the navigation and CSS Grid for the services, gallery and contact sections. I also added hover effects so that some elements change when the user moves the mouse over them. Media queries were added to make the website responsive on tablets and mobile phones. I used relative units such as rem and percentages so that the content can adjust to different screen sizes. The images were also given responsive widths so they can fit different devices. This improves the appearance, usability and responsiveness of the Greenleaf Garden Services website.
